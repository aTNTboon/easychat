EasyMeet 是一款面向企业的实时视频会议协作平台，提供高清音视频通话、屏幕共享、会议录制与回放、实时聊天等核心能力。后端采用 Spring Boot 作为主体框架，基于 WebRTC + SFU 媒体架构保障高并发下的低延迟通信，同时融合了企业级权限管理、会议数据统计与全链路运维监控体系。

✨ 核心功能
🎥 多人音视频通话：基于 WebRTC 实现端到端实时音视频传输，支持 SFU 选择性转发，大幅降低客户端带宽压力。

🖥️ 屏幕共享与协作：支持多端屏幕共享，助力远程演示与协同办公。

📹 会议录制与回放：云端录制会议全程，支持会后随时回放复盘。

💬 实时聊天互动：会议进行中支持文字消息、表情互动，提升沟通效率。

🔐 企业级权限管控：基于 JWT 的身份认证、会议密码保护、主持人/参会者角色分级管理。

🏗️ 技术架构
组件	技术选型	作用
核心框架	Spring Boot	应用主体框架，提供 IOC 与业务调度能力
ORM 层	MyBatis-Plus	简化数据持久层开发，高效处理 CRUD
数据库	MySQL	存储用户信息、会议记录、聊天历史等结构化数据
分布式缓存	Redis	维护房间在线成员列表、Token 黑名单、分布式会话
消息队列	RabbitMQ	异步处理会议录制通知、邮件邀请、操作日志落库
实时通信层	Netty + WebSocket	构建高性能信令服务，承载实时交互指令
媒体传输	WebRTC + SFU	实现音视频流的高效转发与媒体协商

1. 📡 高性能信令服务设计（WebSocket + Netty）
负责设计并实现了基于 WebSocket 的信令服务，全面覆盖用户加入/退出房间、SDP 媒体协商（Offer/Answer）、ICE 候选者交换、成员状态同步等核心实时交互逻辑。

技术深耕：基于 Netty 对 WebSocket 长连接进行深度改造，通过优化线程模型（主从 Reactor）与内存池化（PooledByteBufAllocator），有效规避了频繁 GC 问题，使得单节点能够稳定支撑 5,000+ 并发连接。

集群可靠投递：为解决多节点集群环境下的信令路由问题，利用 Redis Pub/Sub 实现跨节点消息广播，保障了任意房间内的信令指令都能精准、可靠地投递至目标用户。

2. 🚪 房间生命周期与状态管理
承担房间核心业务逻辑开发，包括房间的创建/即时销毁、密码保护机制、主持人权限移交与降级等完整业务流程。

实时状态同步：精心设计 Redis 数据结构（Hash + Set），高效维护房间内的在线成员列表。结合 WebSocket 连接事件监听，实现了成员上下线状态的秒级实时感知与广播通知，确保了会议过程中成员列表的强一致性。

3. 🔐 轻量级高性能权限拦截方案
摒弃传统的 Spring Security 重量级框架，采用 JWT + 自定义 HandlerInterceptor 实现身份鉴权。该方案代码侵入性极低，且通过内存级缓存与简洁的解析逻辑，将认证链路耗时严格控制在 5ms 以内，对业务线程几乎无阻塞影响。

基于 Redis 实现 Token 黑名单机制（配合过期时间 TTL），完美支持用户强制下线、多端登录互踢等企业级安全管控场景，有效防止 Token 盗用风险。
